World

Players can switch 2D / 3D with 🎥 (or V) while playing. In 2D you run left and right, and everything lines up side by side.

Script API
game.part("Name") a part by name
game.find("tag") parts with a tag/type
part.x / .y / .z / .sx / .ry / .color / .visible / .collide / .glow
part.onTouch(fn) when the player touches it
part.move(dx, dy, dz) part.destroy() part.clone({x}) part.setText("hi")
game.create("block", {x, y, z, color})
game.onStart(fn) game.onUpdate(dt => …)
game.onKey("e", fn)
player.x / y / z / speed / jumpPower / color player.respawn() player.launch(30)
game.say("text") game.score += 1 game.win("text") game.lose()
await game.wait(2) game.random(1, 6) game.sound(440, 0.2) game.sky("#000") game.gravity = 30
game.view = "2d" or "3d" switch the view (players can press 🎥 / V too)
console.log(...) shows in 🧾 Output

UI (HTML): your HTML and CSS sit on top of the game. Scripts can change it with document.getElementById.

Built in: Coins add to the score, Kill bricks send you back, Bounce pads launch you, the Goal wins, you start on the Spawn.
